# Changelog

## 0.2.3

* Stack the standard triggers above the bumpers on the front preview, with the custom bumpers on the rear.

## 0.2.2

* Refit the Vader 5S preview with matching face buttons, distinct shoulder controls and rear paddles.
* Show live D-pad, face, menu, bumper, trigger, and stick activity when one XInput controller is connected.

## 0.2.1

* Show front and rear views with the Vader 5S extra buttons in their hardware positions.
* Pause mapped keyboard output while the mapper is focused. Controller activity remains visible.

## 0.2.0

* Redesigned Mappings, App rules, Settings, and Updates pages.
* Enable or pause mapping for individual foreground apps by executable name or path.
* Pause mapping from the window or tray. Buttons held while paused must be released before they map again.
* Choose from three themes and four accent colors, and adjust startup, tray, and logging behavior.
* Existing key assignments and the GTA/FiveM preference carry over.

## 0.1.0

* Six independent Vader 5S extra-button mappings to keyboard/numpad keys.
* Background USB reader with descriptor-based channel/address discovery and reconnection.
* Keyboard Listen buttons and optional GTA/FiveM focus gating.
* Optional startup in the tray through an elevated sign-in task.
* Updates tab checks this repository's stable GitHub Releases.
* Self-contained Windows x64 installer with optional official USBPcap driver setup and matching source/licenses.
* Per-user settings preserved across upgrades; Flydigi Store component imported locally rather than redistributed.
