# Changelog

## 0.1.0

* Six independent Vader 5S extra-button mappings to keyboard/numpad keys.
* Background USB reader with descriptor-based channel/address discovery and reconnection.
* Keyboard Listen buttons and optional GTA/FiveM focus gating.
* Optional startup in the tray through an elevated sign-in task.
* Updates tab checks this repository's stable GitHub Releases.
* Self-contained Windows x64 installer with optional official USBPcap driver setup and matching source/licenses.
* Per-user settings preserved across upgrades; Flydigi Store component imported locally rather than redistributed.
