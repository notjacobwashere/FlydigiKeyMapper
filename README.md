# Flydigi Key Mapper

Map your **Vader 5S** extra buttons to keyboard and numpad keys, including in the background.

## [Download installer for Windows](https://github.com/notjacobwashere/FlydigiKeyMapper/releases/latest)

1. Download and run the **Setup EXE**. Setup includes .NET and the USBPcap driver, and gets the required Flydigi app from Microsoft Store if missing. Store approval or sign-in may be needed.
2. Restart Windows if setup installs the USB driver. Connect one Vader 5S by USB and close Flydigi's app.
3. Click **Listen** beside a button and press the keyboard key you want. Bind that key in your game.

Enable **Start with Windows** to run in the tray. Check the **Updates** tab for newer versions. Setup opens the mapper when finished and upgrades preserve your mappings.

Windows 10/11 x64. Administrator approval is required. The mapper installer is unsigned. Wireless connections and simultaneous extra-button combinations are not supported reliably.
